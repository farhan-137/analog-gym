# Obsidian guide

Back to [[Home]].

## What Obsidian is

Obsidian is a note app that works on **plain files on your Mac**. Every note is a `.md` (Markdown) text file inside one folder, called a **vault**. Nothing goes to the internet; there is no account. If Obsidian disappeared tomorrow, your notes would still be ordinary text files.

What makes it special is **links**. Writing `[[Lec 07]]` inside a note makes a clickable link to the note called *Lec 07*. Obsidian keeps track of every link in both directions, so each note also knows who links *to* it (its **backlinks**). Those links are what draw the "brain" picture, the **graph view**.

This vault is generated from your Analog Gym app: lectures, topics, every question, formulas, flashcards and symbols, all linked to each other.

## One-time setup

1. Download Obsidian from **obsidian.md** and install it (drag to Applications).
2. In Terminal: `cd` into the analog-gym folder and run `git pull`.
3. Double-click **Set up Obsidian vault.command** in the analog-gym folder. It copies the big PDFs and the animated lessons into the vault (they are too big to keep in git twice). If macOS blocks it: right-click → Open → Open.
4. Open Obsidian → **Open folder as vault** → choose the **Analog VLSI Vault** folder inside analog-gym.
5. When it asks **"Do you trust the author of this vault?"**, choose **Trust author and enable plugins**. This turns on the bundled flashcard plugin (Spaced Repetition). If you missed it: Settings → Community plugins → turn off Restricted mode → enable *Spaced Repetition*.

Repeat steps 2–3 after any future update.

## The tour

| Want to… | Do this |
|---|---|
| See the brain picture | **Cmd+G** (graph view). Drag nodes, scroll to zoom, hover a node to light up its links. |
| See just one note's neighbours | Open a note → **Cmd+P** → "Open local graph". |
| Jump to any note by name | **Cmd+O**, type `lec 9` or `slew` and press Enter. |
| Search inside every note | **Cmd+Shift+F**. |
| Run any command | **Cmd+P** (command palette). |
| Go back / forward | **Cmd+[** and **Cmd+]**. |
| Open a link in a new tab | **Cmd+click** the link. |
| See who links here | Right sidebar → Backlinks (or Cmd+P → "Show backlinks"). |
| Switch reading ↔ editing | **Cmd+E**. |

### Graph colours

| Colour | Notes |
|---|---|
| White, big | [[Home]] |
| Orange | Lectures (`01 Lectures`, e.g. [[Lec 06]]) |
| Purple | Topics (`02 Topics`) |
| Red | Mid-sem and quiz questions |
| Blue | Other questions (tutorials, worked examples) |
| Yellow | [[Formula sheet]] and flashcards |
| Pink | Your own notes (`My notes`) |

Symbol notes (like gm or rO) are hidden from the big graph so it stays readable; you still see them in each note's local graph. To show them: graph settings (gear icon) → Filters → clear the search box. Every link in the vault is checked when it is built, so there are no broken links and no empty "ghost" nodes.

## How to study with it

- **Start from a lecture.** Open e.g. [[Lec 07]]: your scanned page, the formulas, the explanation, then every question that uses that lecture.
- **Questions.** Each question note has the printed question, the givens and a **Your attempt** section. Solve on paper first. The hints, the answer and the full solution are in **collapsed boxes**: click the arrow to open one only when you need it.
- **All questions in one list:** [[All questions]].
- **Formulas:** [[Formula sheet]]. Since you can't carry a cheat sheet, use the flashcards below to drill them.
- **Symbols:** [[Symbols]] explains every letter (gm, rO, λ, ωu…).
- **PDFs and the animated lessons:** [[Papers and lessons]]. Click a link to open it in Obsidian or your browser.

## Flashcards (Spaced Repetition)

Cards look like `front::back` inside the flashcard notes, e.g. [[Flashcards – Lecture formulas]].

1. Click the **cards icon** in the left ribbon (or Cmd+P → "Spaced Repetition: Review flashcards in all notes").
2. Pick a deck. Say the answer out loud, then click **Show answer**.
3. Grade yourself: **Hard**, **Good** or **Easy**. Cards you find hard come back sooner.

Do one round each evening, plus one in the morning before the exam.

## Your own notes

Anything you write in **My notes** is yours. Rebuilding the vault never touches that folder (all the other folders are regenerated). New notes (**Cmd+N**) go there automatically. Link them to anything: type two opening square brackets and start typing a name, e.g. Lec 10, pick it from the list, and they will show up in pink in the graph.

Do **not** edit notes in the other folders; your changes would be overwritten at the next rebuild. Copy a bit into My notes instead.

## Rebuilding (for later)

The vault is generated by `node scripts/vault/build.mjs` in the analog-gym folder (needs `npm ci` once). It rewrites everything except My notes and checks every link.
