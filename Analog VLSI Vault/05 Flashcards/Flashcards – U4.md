# Flashcards – U4

Topic: [[U4 Small signal]]

Write gm three ways.::gm = µCox(W/L)Vov = √(2µCox(W/L)ID) = 2ID/Vov.
Which face of gm for a headroom question?::gm = 2ID/Vov (the designer’s form).
Output resistance of a saturated MOSFET?::rO = 1/(λID) = VA/ID.
Intrinsic gain, and when is it independent of ID?::gm·rO = (2ID/Vov)·(1/λID) = 2/(λVov): at a fixed overdrive ID cancels. In a fixed-size device more ID means more Vov and less gain.
Three small-signal conversion rules?::DC voltage sources → AC ground; DC current sources → open; transistor → gm·vgs ‖ rO.
