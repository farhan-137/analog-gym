# Flashcards – L9

Topic: [[L9 Input range and slew rate]]

When does an op amp slew?::When the linear response would need a slope above SR: V0·ACL/τ > ISS/CL.
Folded cascode slew rate?::ISS/CL if the folding current IP ≥ ISS; otherwise IP/CL (a cascode branch turns off).
