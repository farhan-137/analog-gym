# Flashcards – U2

Topic: [[U2 Triode, saturation, pinch-off]]

NMOS saturation condition in node voltages?::VD ≥ VG − Vth (equivalently VDS ≥ Vov).
PMOS saturation condition in node voltages?::VD ≤ VG + |Vth|.
Why does ID stop growing once VDS > Vov?::The channel has pinched off; extra VDS drops across the gap near the drain. The current is set upstream by Vov (the waterfall).
Saturation current (square law)?::ID = ½ µCox (W/L) Vov² (1 + λVDS); use λ = 0 for DC bias.
Triode current?::ID = µCox (W/L)[Vov·VDS − VDS²/2].
W/L for a given ID and Vov?::W/L = 2ID/(µCox Vov²).
