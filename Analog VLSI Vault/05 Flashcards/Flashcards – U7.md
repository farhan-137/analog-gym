# Flashcards – U7

Topic: [[U7 CS with every load + degeneration]]

CS gain with a current-source load?::Av = −gm1(rO1 ‖ rO2).
CS gain with a diode load (λ = 0)?::Av = −gm1/gm2 = −√(µn(W/L)1/(µp(W/L)2)).
CS gain with an active (CMOS) load?::Av = −(gm1 + gm2)(rO1 ‖ rO2).
Gm of a degenerated CS stage?::gm/(1 + gm·RS) = 1/(1/gm + RS).
State the ratio rule.::|Av| = (resistance at the output terminal) ÷ (resistance in the source path, with the transistor as 1/gm).
