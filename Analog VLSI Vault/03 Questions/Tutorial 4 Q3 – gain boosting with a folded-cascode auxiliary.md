## Question

VDD = 3 V, 3 mW in total, µnCox = 200 µA/V², µpCox = 100 µA/V², λn = 0.1 V⁻¹, λp = 0.2 V⁻¹, Vthn = 0.7 V, |Vthp| = 0.8 V. M1 = M2 = 100/0.5 carrying 500 µA. (W/L)5 = (W/L)8 = 0.4(W/L)6, (W/L)3 = 0.5(W/L)6, (W/L)4 = (W/L)9 = (W/L)1. (a) For a 2.5 V output swing, (W/L)6. (b) With VP = Vov1, R3. (c) With VDS9 = 1.15·Vov9, is M4 saturated? (d) (W/L)7, R1, R2. (e) The overall gain.

| Given | Value |
|---|---|
| $V_{DD}$ | 3 V |
| $P$ | 3 mW |
| $I_{D1}$ | 500 µA |
| $(W/L)_{1}$ | 200 |

**Find:** (a) Size of M6 · (b) R3 · (c) M4 region · (d) Size of M7 · (d) R1 · (d) R2 · (e) Overall gain

## Your attempt

- 

> [!tip]- Hints (open one at a time)
> 1. Start from the power: 1 mA shared between the branches; equal |VGS| means currents scale with W/L.
> 2. Swing: Vout from 2Vov1 to VDD − |Vov6|.
> 3. R3 = (VDD − VP − |VGS3|)/I3; walk the bias string node by node.
> 4. Vov1 = 0.1581 V.

> [!info]- Concept and formulas
> Folded-cascode auxiliary (Lec 8 implementation 3): budget the currents from the power, size from equal VGS/mirror ratios, walk the bias string, then gain = gm1 × (boosted Rdown ‖ Rup).
> $$I_{tot} = P/V_{DD}$$
> $$\dfrac{(W/L)_a}{(W/L)_b} = \dfrac{I_a}{I_b}\;(\text{same }V_{GS})$$

> [!success]- Answers
> - (a) Size of M6: **296.1**
> - (b) R3: **19.26 kΩ**
> - (c) M4 region: **0**
> - (d) Size of M7: **133.3**
> - (d) R1: **5.377 kΩ**
> - (d) R2: **591.9 Ω**
> - (e) Overall gain: **63.14 V/V**

> [!example]- Full solution
> 1. Power budget: 3 mW / 3 V = 1 mA. M6 500 µA; M8 and M5 are 0.4× M6 at the same |VGS|: 200 µA each; M3 gets what is left, M9 sinks I4 + I3
>    $$I_3 = 1 - 0.5 - 0.2 - 0.2 = 100\,\mathrm{\mu A},\; I_9 = 300\,\mathrm{\mu A}$$
> 2. (a) Vout runs from 2Vov1 (M1, M2 identical) up to VDD − |Vov6|
>    $$|V_{ov6}| = 3 - 2.5 - 2(0.1581) = 0.1838\,\mathrm{V} \Rightarrow (W/L)_6 = \frac{2(500\mu)}{100\mu\,(0.1838)^2} = 296.1$$
> 3. (b) M3 (W/L = ½(W/L)6, 100 µA) has its gate at VP = Vov1; its source sits |VGS3| higher; R3 drops the rest
>    $$V_{S3} = 0.1581 + 0.8 + 0.1162 = 1.074\,\mathrm{V},\; R_3 = \frac{3 - V_{S3}}{100\mu} = 19.3\,\mathrm{k\Omega}$$
> 4. (c) Node F = 1.15·Vov9; VG4 = F + VGS4; M4’s drain is M2’s gate = VP + VGS2. Fence: VD4 ≥ VG4 − Vth
>    $$V_{D4} = 1.016\,\mathrm{V} \ge 0.2408\,\mathrm{V}\;\checkmark$$
> 5. (d) M7 mirrors M9 (same VGS): widths scale with current
>    $$(W/L)_7 = 200\times\frac{200\mu}{300\mu} = 133.3$$
> 6. Walk the bias string: R2 from VGS7 up to VG4, R1 from VG4 up to M8’s drain (VDD − |VGS8|)
>    $$R_2 = \frac{0.9408 - 0.8225}{200\mu} = 592\,\mathrm{\Omega},\; R_1 = \frac{2.016 - 0.9408}{200\mu} = 5.38\,\mathrm{k\Omega}$$
> 7. R1: from VG4 up to M8’s drain
>    $$R_1 = \frac{2.016 - 0.9408}{200\mu} = 5.38\,\mathrm{k\Omega}$$
> 8. (e) Auxiliary gain: M3 is degenerated by R3 (Gm3 = gm3/(1 + gm3R3)) into rO5 ‖ (M4 cascoded over rO9)
>    $$A_{aux} = 50.4\,\mu S \times 24.9\,\mathrm{k\Omega} = 1.26$$
> 9. Boosted Rdown is MΩ, but M6 is a simple source (rO6 = 10 kΩ): smallest in parallel wins
>    $$|A_v| = g_{m1}(R_{boost}\parallel r_{O6}) = 6.325\,\mathrm{mS}\times(5.75\,\mathrm{M\Omega}\parallel 10\,\mathrm{k\Omega}) = 63.14$$
